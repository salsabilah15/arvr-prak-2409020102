## Jawaban Refleksi

1. Posisi objek pakai z negatif karena kamera default menghadap ke sumbu -Z. Jadi kalau z positif malah di belakang kamera dan tidak terlihat.

2. WebXR hanya aktif di HTTPS atau localhost untuk keamanan. Karena WebXR bisa akses sensor dan kamera device, jadi browser harus pastikan koneksinya aman.

3. WebXR Device API itu jembatan low-level biar browser bisa ngobrol sama headset VR. Three.js itu library buat gambar 3D. A-Frame itu bungkus Three.js biar kita bisa bikin VR pakai tag HTML aja.
